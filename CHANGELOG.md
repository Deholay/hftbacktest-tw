# Changelog

All notable changes to this project are documented in this file.

## [0.3.0] - 2026-09-03

### Added

- Standalone Python package and Rust native runtime.
- Neutral two-asset compact-BBO replay API.
- Strict immediate FOK/IOC matching with independent feed, entry, and response latency.
- Versioned `bbo_v1` Arrow cache schema and streaming cache builder.
- Native library builds as part of Python source and wheel builds.
